# 本版修改文件

当前有效说明为 `README.md`、`交付说明.md` 和 `docs/paper_simd_20260922.md`，历史说明位于 `docs/history/`。

| 文件/模块 | 改动 |
|---|---|
| core/rrtstar.h | 去掉排序后的 Top-K 截断、rewire 尝试次数截断；保留成本排序，增加 rewire 内层超时检查 |
| common/planner_config.h | 移除 top_k，旧 precheck 开关改为通用 candidate_precheck；机器人没有该预检路径 |
| common/types.h、benchmark/benchmark_result.h | 增加 SIMD 物理验证计数和真实 backend 标签 |
| simd/float8.h | 独立 AVX2 float8 数学、角函数近似、三维向量运算 |
| df/simd_inverse.h | 三系统批量 DF 状态/控制逆变换及物理约束 |
| simd/physical_batch.h/.cpp | POD SoA 接口、CPU 检测、球体 BVH 构建，无标量回退 |
| simd/physical_avx2.cpp | Bernstein 批量求值、DF、物理约束和球体碰撞融合内核 |
| simd/discrete_validator.h | 分辨率、交错采样、mask、统计、物理轨迹输出 |
| dynobench/data_adapter.h/.cpp | 仅读取数据；明确控制映射、障碍球覆盖、轨迹/几何导出 |
| systems/batch_config.h | 编译期系统配置→SIMD 参数映射 |
| systems/dyno_model.h | 搜索与 lifting 保留；原标量验证区域替换为单一 SIMD 路径 |
| systems/robot_factory.h | 切换到 data-only adapter 与 Paper*Model |
| benchmark/robot_runner.cpp | 删除真实 FCL/step 检查；新增输出 backend/geometry；最终长度使用导出位置采样 |
| benchmark/benchmark_runner.h | 接入新可执行路径，去掉 top_k 参数 |
| 六 YAML | 明确球体几何与 simd_discrete_float8；保留 dt、动力学、PFF 与采样配置 |
| CMakeLists.txt | 编译新内核/数据适配器；不链接外部 DynoBench/FCL |
| tools/run_six.py | 使用数据目录执行六场景，取消外部 checker；结果名 sampled_successes |
| tests | 新增 physical_simd、sphere_geometry；保留 PFF/DF/树等回归；更新配置测试 |
| reference/legacy_validation | 归档旧标量验证及旧验证脚本，当前 CMake 不编译/调用 |

PFF 内部数学和候选时间集合未修改；取消 Top-K 会改变可选边集合，因此不能要求新旧树逐节点一致。物理有效性判断从原来的混合验证切换为论文式 SIMD 离散验证，这是本次明确授权的行为变化。
