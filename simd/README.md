# SIMD 路径

规划期的机器人碰撞屏幕采用论文中的离散时间采样语义：一条时间参数化
`FlatTrajectory` 被均匀采样，八个连续采样点放入一个 `__m256`（8 个
`float` lane），批量计算多项式位置并做 inscribed-sphere/AABB 拒绝。
通过屏幕只表示“没有在这些采样点发现碰撞”，不会绕过真实验证。

候选父节点仍以逻辑宽度 8 进行 PFF 批处理；这是候选维度，和碰撞屏幕的
八个时间采样 lane 是两个独立的批处理轴。最终进入树前仍执行 scalar
FCL/DynoBench，最终导出的路径还执行完整的 scalar checker。这样保留了
论文的快速离散拒绝路径，同时避免用简化几何替代真实模型验证。
