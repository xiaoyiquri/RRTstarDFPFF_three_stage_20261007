## A′ 诊断结果与解释

本次 paper_r2 四个 Quad 均为 sampled_success=1、physical_boundary_match=0。
下面的最大值包含起点、所有连接点、终点诊断，不专指某一个连接。

| 环境 | 最大姿态误差 rad | 最大角速度误差 rad/s |
|---|---:|---:|
| Quad2D Bugtrap | 0.159605 | 0.116161 |
| Quad2D Hole | 0.098740 | 0.077622 |
| Quad3D Block | 0.118704 | 0.059197 |
| Quad3D Window | 0.123602 | 0.081125 |

这些误差根据用户确认的 A′ 保留为诊断，不拒绝 paper_r2 路径。
成功只代表二阶 flat 边界契约及每条边的采样物理约束/碰撞检查通过；不代表原请求的全部姿态/角速度均满足或物理连接连续。
轨迹 YAML 明确写出 `reduced_order_result: true`、`junction_attitude_omega_policy: diagnostic_only` 和 `physical_continuity_certified: false`。
full_df 的五个成功结果均 physical_boundary_match=1。

精度仍为原混合精度；没有调用 DynoBench/FCL runtime，没有作连续碰撞证明，也没有运行正式 20 seeds / 120 s 论文实验。
