## 编译与测试

本机 Windows x86-64，已有 Zig 0.13/Clang 18、AVX2。全部目标编译成功，CTest **12/12**。测试日志：`validation_logs/ctest_final.log`。Linux/虚拟机的编译运行还需要在你的虚拟机执行 README 中的命令，本次不伪称已在那里测试。

`physical_simd` 包括三系统、双 velocity branch 的 4000 个随机物理状态与控制参考对照、不同持续时间的完整高阶 PFF 曲线对照、NaN/零速/零推力/共线奇异性、状态和控制超界、有效 mask、首尾点、Top-K 删除测试。`sphere_geometry` 对照二维/三维 BVH 与独立暴力球体距离检查，并验证盒体球覆盖。标量 reference 只用于测试，不在候选验证调用链里。

原来名为 `dynobench` 的 CTest 是保留的基础 adapter 单元测试；它不是新的真实 DynoBench 集成认证。旧 `real_dynobench` 和依赖旧 Top-K/FCL 几何的整树快照测试不再适用于本版，历史实现归档，当前物理判据用上述两项 SIMD 测试验证。

## 本版几何与结论边界

Uni 半径 0.125 m、Quad2D 半径 0.1 m、Quad3D 半径 0.25 m；这是明确的球体模型适配值，**不是原矩形机体的外接球保证**。地图盒体采用最大格边 0.1 m 的外接球并集覆盖；保存实际 `geometry.yaml`，用于按新模型复现。这些适配值不能说是论文公布的全部参数。

通过仅表示指定分辨率、几何及 float32 计算下采样点可行。没有连续无碰撞、无奇异点证明，也没有 DynoBench 真值验证。输入 lifting、PFF 求解、树/metadata 结构检查及结果序列化依旧保留必要的标量运算。

## DynoBench 源数据去重

运行器现在把 `--dynobench-source` 作为唯一的官方数据根目录：环境从 `source/envs` 读取，未覆盖的模型从 `source/models` 读取。原项目内与官方完全相同的 `benchmark/models/paper/quad2d_v0.yaml` 已删除。Uni 与 Quad3D 的三个模型文件仍保留，因为它们包含论文实验明确覆盖的动力学参数；它们由各自配置的 `dynobench.model_file` 显式引用。球体几何适配和本地结果绘图不是重复的 DynoBench 功能，原因是本版本的权威判据是球体并集 + 5 ms 离散 float8 检查，而 DynoBench viewer 显示的是原始盒体环境。

构建和运行指令见 `README.md`；公式、接口与计数口径见 `docs/paper_simd_20260922.md`。此版不声称完整复现 FLASK 全局规划器，仍是你的 RRT* + PFF。
