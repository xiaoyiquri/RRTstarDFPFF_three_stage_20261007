# 运行指令

从本副本目录执行。运行输出目录必须是新目录。

## 本机离线构建

本次使用已有 Zig 0.13 / CMake / Ninja / Eigen 3.4 / yaml-cpp 0.8；不需要 DynoBench/FCL runtime。

```powershell
$cmakeExe = 'D:\codex_talk\project_1\tmp\simd-build-tools\cmake\data\bin\cmake.exe'
& $cmakeExe -S . -B build_r2 -G Ninja '-DCMAKE_MAKE_PROGRAM=D:/codex_talk/project_1/tmp/simd-build-tools/bin/ninja.exe' '-DCMAKE_TOOLCHAIN_FILE=D:/codex_talk/project_1/tmp/zig-toolchain.cmake' '-DRRTPFF_EIGEN_SOURCE=D:/codex_talk/project_1/tmp/eigen-3.4.0' '-DRRTPFF_YAML_SOURCE=D:/codex_talk/project_1/tmp/yaml-cpp-0.8.0' '-DCMAKE_BUILD_TYPE=Release' '-DCMAKE_CXX_FLAGS_RELEASE=-O3 -DNDEBUG' '-DCMAKE_POLICY_VERSION_MINIMUM=3.5' '-DBUILD_TESTING=ON' '-DRRTSTARDFPFF_ENABLE_AVX2=ON'
& $cmakeExe --build build_r2 --parallel 2
& 'D:\codex_talk\project_1\tmp\simd-build-tools\cmake\data\bin\ctest.exe' --test-dir build_r2 --output-on-failure
python -m unittest tests.test_run_six -v
```

一般环境可以用 CMake 3.16+ 和 Eigen/yaml-cpp 包配置正常构建，编译器使用系统可用的 C++17 工具链。
AVX2 CPU 是本运行器的要求。混合精度仍为 PFF double / 时间根 long double / 物理 SIMD float32。

## 选择模式

```powershell
python tools/run_six.py --dynobench-source ../dynobench-main/dynobench-main --build-dir build_r2 --df-mode paper_r2 --runs 1 --timeout 5 --seed 41 --output results/new_r2_run
python tools/run_six.py --dynobench-source ../dynobench-main/dynobench-main --build-dir build_r2 --df-mode full_df --runs 1 --timeout 5 --seed 41 --output results/new_full_run
```

`--cases uni_wall quad2d_hole` 可只运行指定环境。
上述是短时运行命令，不是正式论文协议。

## 输出检查

`results.csv`：算法结果及模式、边界契约、精度。
`validation.csv`：规划成功和最终采样验证结果。
`boundary_diagnostics_N.csv`：起点、每个连接点、终点的 flat/物理误差。
`trajectory_N.yaml`：最终验证通过才生成，并标记降阶及连续性语义。
`manifest.json`：模式、输入/二进制哈希、运行预算。

paper_r2 的 sampled_success 不表示请求的姿态/角速度都满足，也不表示物理连接连续。必须结合诊断解释。
