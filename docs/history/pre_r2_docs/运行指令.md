以后绘图时使用下面命令，**只保存文件，不打开浏览器**：

```
plot_dir="$experiment_dir/figures_$(date +%Y%m%d_%H%M%S_%N)"

if MPLBACKEND=Agg python3 "$project_dir/plot_successful_results_paper.py" \
  --experiment "$experiment_dir" \
  --cases "${successful_cases[@]}" \
  --run 0 \
  --output "$plot_dir"
then
  printf '\n已保存到：%s\n' "$plot_dir"
  cat "$plot_dir/metrics.csv"
fi
```
