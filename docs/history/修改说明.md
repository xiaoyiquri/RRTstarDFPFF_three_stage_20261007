## 验证结果

本地使用现有 Clang 18.1.6 / Zig 0.13.0、Eigen 3.4、yaml-cpp 0.8 离线 Release 构建（-O3；AVX2；-ffp-contract=off）。没有安装依赖。

- 缓存终端解后的最终核心 CTest：**12/12 通过**，6.86 s，见 `validation_logs/paper_fast/ctest.log`。
- 本轮 float8 切换后本地 Release CTest：**12/12 通过**；`test_simd` 报告 `Compiled AVX2=1 runtime AVX2=1`，并通过 float8 多项式、AABB 和离散机器人屏幕测试。
- 两项运行脚本单测：**2/2 通过**，见 `runner_tests.log`。验证六环境配置和外部 checker 使用相同模型路径，以及独立开关的传递。
- `benchmark --config` 入口的 AVX2 + deferred 线性烟雾实验：**1/1 成功**，CSV 新字段可正确解析；记录在 `linear_deferred_smoke/`。这是线性基线，不是六环境机器人成功证明。
- 三种维度/阶数的 PFF 候选、scalar/SIMD 及物化后曲线一致；双积分器上的 eager/lazy 整树在固定迭代、rewire、目标缓存开/关时逐项一致；独立旧 Quad3D 实现的原配置回归通过。
- `robot_frontend_compile` 编译三个真实机器人的前端模板与集成测试调用；**不等于 real_adapter.cpp 已在本机链接真实 FCL**。
- 新版真实 `real_dynobench`、六环境规划和外部 checker：**本机未执行，待已有 Linux VM**。本机 FCL 依赖不可用，WSL 访问被拒；按用户要求未下载软件。

### 微基准（中位数，每行1280个父节点、19200个时间候选）

只比较相同新版本的 eager 与 deferred PFF，使用同一模型、代价、候选集、双精度和 k=8。包含 checksum 一致性检查。比值为 eager时间 / deferred时间，大于1表示延迟方式更快。不能把这些数字称为真实六环境首解加速。

| FlatDim / Order | 实际访问范围 | eager(ms) | deferred(ms) | 比值 |
|---|---|---:|---:|---:|

| 2 / 2 | 仅首候选 | 30.206 | 24.660 | 1.225 |
| 2 / 2 | 全部候选 | 27.085 | 25.173 | 1.076 |
| 2 / 4 | 仅首候选 | 72.064 | 62.178 | 1.159 |
| 2 / 4 | 全部候选 | 73.703 | 74.371 | 0.991 |
| 4 / 4 | 仅首候选 | 103.252 | 76.389 | 1.352 |
| 4 / 4 | 全部候选 | 98.734 | 103.173 | 0.957 |

只访问首候选时，每行完整轨迹构造从19200次减少为1280次，测得约1.16–1.35倍。全部候选都访问时基本持平，Quad3D 约慢4%；不保证所有场景都加速。微基准时间较短，会受机器负载、缓存与调度影响。

初版曾在物化时重复求解终端条件，导致全部候选访问明显变慢；最终版缓存相同的 eta/能量消除了重复求解。修正前数据单独存为 `pff_microbenchmark_before_cache.csv`，不与最终数据混淆。最终数据是 `pff_microbenchmark.csv`。
